# NineLives.API — Requirements Specification

> **Version:** 1.0 (MVP)

---

# 1. Purpose

This document defines the functional and non-functional requirements for Version 1.0 of **NineLives.API**.

The objective is to establish a clear agreement on what the system must do before development begins.

---

# 2. Scope

Version 1.0 focuses on the core functionality required to manage rescued cats.

## Features Included

- Register rescued cats
- View rescued cats
- View rescued cat details
- Update rescued cat information
- Soft delete rescued cats

## Features Excluded

- Authentication
- Adoption management
- Reporting
- Other advanced features

---

# 3. Functional Requirements

## FR-001 — Register Rescued Cat

### Input

| Field				| Req|
|-------------------|:--:|
| Name				| ❌ |
| Estimated Age		| ❌ |
| Gender			| ✅ |
| Breed				| ❌ |
| Color				| ✅ |
| Description		| ❌ |
| Rescue Date		| ✅ |
| Rescue Location	| ✅ |
| Vaccination Status| ✅ |
| Current Status	| ✅ |
| Health Notes		| ❌ |

### Processing

- Validate required fields
- Generate unique Rescue ID
- Record `CreatedAt`
- Save rescued cat

### Response

- `201 Created`
- Return created rescued cat

---

## FR-002 — View All Rescued Cats

Processing

- Exclude soft deleted records
- Return active rescued cats only

Response

- `200 OK`

---

## FR-003 — View Rescued Cat Details

**Input**

- Rescue ID

**Response**

- `200 OK`
- `404 Not Found`

---

## FR-004 — Update Rescued Cat

Processing

- Validate input
- Update `UpdatedAt`

Response

- `200 OK`
- `404 Not Found`

---

## FR-005 — Soft Delete Rescued Cat

Processing

- Mark record as deleted
- Record deletion status
- Exclude deleted records from searches

Response

- `204 No Content`

|--------|----------------------------------------------------------------------------------|
| BR-001 | Cat Name is optional																|

| BR-003 | Gender: Male, Female, Unknown													|
| BR-004 | Color is required																|
| BR-005 | Breed is optional																|
| BR-006 | Rescue Date is required															|
| BR-007 | Rescue Location is required														|
| BR-008 | Description is optional															|
| BR-009 | Health Notes are optional														|
| BR-010 | Vaccination Status: Unknown, Not Vaccinated, Vaccinated							|
| BR-011 | Status: Rescued, Under Treatment, Fostered, Ready for Adoption, Adopted, Deceased|
| BR-012 | Rescue ID generated by backend													|
| BR-013 | Rescue ID must be unique															|
| BR-014 | Deleted records hidden from active searches										|
| BR-015 | CreatedAt generated automatically												|
| BR-016 | UpdatedAt updated automatically													|
